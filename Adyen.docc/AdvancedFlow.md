# Advanced flow integration guide

> Note: This guide is being updated for v6.

The advanced flow starts with the `/paymentMethods` API call and gives you more control over the checkout flow.

The v6 advanced flow integration is being migrated to the new ``Checkout`` API. Up-to-date integration steps and code samples will be published here once the migration is complete.

See <doc:API-Reference> for the available public types in the meantime.
